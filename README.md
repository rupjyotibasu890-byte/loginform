## 📖 Project Overview
This project is a simple **user registration and login system** built with **PHP** and **MySQL**, hosted entirely on **InfinityFree**.  
It allows users to register with a username, email, and password.  
All data is securely stored in a MySQL database using prepared statements and password hashing.
